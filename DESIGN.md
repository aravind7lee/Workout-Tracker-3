# GrindX UI system

- **Surfaces:** `--bg`, `--bg-soft`, `--bg-accent`; dark is near-black and light is cool white.
- **Type:** high-contrast display headings, readable neutral body text, uppercase utility labels only for short navigation/status labels.
- **Spacing:** 8px base rhythm; page gutters 16px mobile / 24px tablet / 48px desktop.
- **Shape:** 12px cards, 16px panels, full-round controls only for compact icon actions.
- **Feedback:** red is the primary action/accent; green, amber, and red communicate success, caution, and error without being the sole indicator.
- **Interaction:** 44px minimum touch target, visible keyboard focus, subtle 180–300ms motion, and reduced-motion support.
- **Theme rule:** preserve deliberate media/dark surfaces; theme only surrounding UI and maintain readable foreground contrast.
