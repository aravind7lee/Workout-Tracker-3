# Stitch Code-To-Design Skill

Convert existing frontend application code into Stitch projects and design systems.

## Workflow
1. Scan local frontend code in the target path.
2. Extract design tokens and structure.
3. Use Stitch MCP `create_project` to initialize a new Stitch project.
4. Upload extracted design specifications or screens to Stitch.
