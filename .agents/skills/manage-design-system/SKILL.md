# Stitch Manage Design System Skill

Manage and apply design systems within Stitch projects using the Stitch MCP tools.

## Tools Used
- `upload_design_md`: Upload a DESIGN.md markdown definition to a Stitch project.
- `create_design_system`: Create a new design system from scratch.
- `create_design_system_from_design_md`: Parse DESIGN.md into a design system.
- `apply_design_system`: Apply design tokens and theme rules to target Stitch screens.
- `list_design_systems` & `update_design_system`: Query and update existing design systems.
