🎯 How It Works

🔄 Auto-Refresh Every 30 Seconds
  1. Initial Load: Dashboard fetches all data on component mount
  2. Background Polling: Service polls backend every 30 seconds
  3. Smart Caching: Reduces redundant API calls
  4. Live Updates: UI updates automatically with new data
  5. Manual Refresh: Users can force refresh anytime
  6. Error Handling: Graceful fallback to cached data
